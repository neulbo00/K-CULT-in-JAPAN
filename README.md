# K-CULT-in-JAPAN

일본 내 한류 이벤트와 공연 일정을 살펴보는 데이터 대시보드입니다.

- **공개 사이트**: https://neulbo00.github.io/K-CULT-in-JAPAN/
- **데이터 원본**: Notion 일본 한류 이벤트 DB
- **배포 구조**: GitHub Pages 정적 사이트
- **2.0 개발 브랜치**: `feature/kcult-v2-foundation`

## K-CULT 2.0

현재 2.0 작업은 기존 데이터 구조를 유지하면서 다크 테마 대시보드로 화면을 재구성하는 단계입니다.

- 전체 이벤트 현황
- 월별 이벤트 추이
- 이벤트 유형 및 카테고리 통계
- 주요 프로모터 통계
- 공개 데이터에 포함된 다가오는 일정 검색 및 유형 필터
- 일본 8개 권역 지도·차트 영역 (Notion 지역 데이터 연결 후 활성화 예정)

## 데이터 범위 및 주의사항

현재 `data.js`는 통계 데이터와 다가오는 일정 미리보기 24건을 포함합니다. 일정 24건은 전체 이벤트 311건의 전체 일정 목록이 아닙니다.

현재 스냅샷 집계 점검 결과:
- 전체 이벤트: 311건
- 유형별 합계: 311건
- 카테고리별 합계: 311건
- 월별 합계: 310건

월별 합계 1건 차이는 원본 날짜와 집계 기준을 추가 확인해야 합니다. 카테고리의 미분류 항목도 임의로 다른 카테고리에 편입하지 않습니다.

지역별 통계는 공개용 데이터 파일에 권역별 집계가 포함된 뒤 실제 수치로 표시합니다. 데이터가 없는 상태에서 임의의 지역별 수치를 만들지 않습니다.

## 배포 원칙

- 2.0 작업은 feature branch에서 검토합니다.
- 기존 `main` 및 공개 페이지는 검증 전까지 변경하지 않습니다.
- Notion 원본 데이터의 공개는 허용 필드만 내보내는 방식으로 제한합니다.
- 데이터 검증 실패 시 공개 배포를 진행하지 않습니다.
